# JavaScript Arrays (Complete Short Notes)

## What is an Array?

* An **Array** is a special object used to store **multiple values** in a single variable.
* Arrays are **0-indexed** (first element is at index `0`).

```javascript
let fruits = ["Apple", "Banana", "Mango"];
```

---

# Creating Arrays

### Array Literal (Recommended)

```javascript
let numbers = [10, 20, 30];
```

### Array Constructor

```javascript
let numbers = new Array(10, 20, 30);
```

---

# Accessing Elements

```javascript
let fruits = ["Apple", "Banana", "Mango"];

console.log(fruits[0]); // Apple
console.log(fruits[1]); // Banana
console.log(fruits[2]); // Mango
```

---

# Updating Elements

```javascript
let fruits = ["Apple", "Banana"];

fruits[1] = "Orange";

console.log(fruits);
```

**Output**

```javascript
["Apple", "Orange"]
```

---

# Array Length

```javascript
let fruits = ["Apple", "Banana", "Mango"];

console.log(fruits.length);
```

**Output**

```javascript
3
```

---

# Adding Elements

## push()

Adds element at the end.

```javascript
fruits.push("Orange");
```

---

## unshift()

Adds element at the beginning.

```javascript
fruits.unshift("Kiwi");
```

---

# Removing Elements

## pop()

Removes the last element.

```javascript
fruits.pop();
```

---

## shift()

Removes the first element.

```javascript
fruits.shift();
```

---

# Searching

## indexOf()

Returns the index.

```javascript
fruits.indexOf("Banana");
```

---

## includes()

Checks whether an element exists.

```javascript
fruits.includes("Apple");
```

**Output**

```javascript
true
```

---

# Joining

## join()

Converts an array into a string.

```javascript
fruits.join(", ");
```

**Output**

```javascript
Apple, Banana, Mango
```

---

# Extracting

## slice()

Returns a new array.

```javascript
let result = fruits.slice(1, 3);
```

Original array remains unchanged.

---

# Modifying

## splice()

Used to add, remove, or replace elements.

### Remove

```javascript
fruits.splice(1, 2);
```

### Add

```javascript
fruits.splice(1, 0, "Orange");
```

### Replace

```javascript
fruits.splice(1, 1, "Orange");
```

---

# Reverse

```javascript
fruits.reverse();
```

---

# Sorting

```javascript
fruits.sort();
```

For numbers

```javascript
let nums = [30, 10, 5];

nums.sort((a, b) => a - b);
```

---

# Concatenate Arrays

```javascript
let a = [1, 2];
let b = [3, 4];

let c = a.concat(b);

console.log(c);
```

---

# Spread Operator

```javascript
let a = [1, 2];
let b = [3, 4];

let c = [...a, ...b];
```

---

# Looping Through Arrays

## for

```javascript
for (let i = 0; i < fruits.length; i++) {
    console.log(fruits[i]);
}
```

---

## for...of

```javascript
for (let fruit of fruits) {
    console.log(fruit);
}
```

---

## forEach()

```javascript
fruits.forEach(function(item) {
    console.log(item);
});
```

Arrow Function

```javascript
fruits.forEach(item => console.log(item));
```

---

# Common Array Methods

## map()

Creates a new array.

```javascript
let nums = [1, 2, 3];

let square = nums.map(num => num * num);

console.log(square);
```

---

## filter()

Returns matching elements.

```javascript
let nums = [10, 20, 30, 40];

let result = nums.filter(num => num > 20);

console.log(result);
```

---

## reduce()

Reduces an array to a single value.

```javascript
let nums = [10, 20, 30];

let sum = nums.reduce((a, b) => a + b);

console.log(sum);
```

---

## find()

Returns the first matching element.

```javascript
let nums = [10, 20, 30];

console.log(nums.find(num => num > 15));
```

---

## findIndex()

Returns the index of the first matching element.

```javascript
console.log(nums.findIndex(num => num > 15));
```

---

## some()

Returns `true` if at least one element satisfies the condition.

```javascript
let nums = [10, 20, 30];

console.log(nums.some(num => num > 25));
```

---

## every()

Returns `true` if all elements satisfy the condition.

```javascript
console.log(nums.every(num => num > 5));
```

---

# Difference: slice() vs splice()

| slice()            | splice()                    |
| ------------------ | --------------------------- |
| Returns new array  | Modifies original array     |
| Original unchanged | Original changed            |
| Used for copying   | Used for add/remove/replace |

---

# Difference: map() vs forEach()

| map()                   | forEach()           |
| ----------------------- | ------------------- |
| Returns new array       | Returns `undefined` |
| Used for transformation | Used for iteration  |

---

# Difference: find() vs filter()

| find()                 | filter()              |
| ---------------------- | --------------------- |
| First matching element | All matching elements |
| Returns one value      | Returns an array      |

---

# Difference: some() vs every()

| some()               | every()        |
| -------------------- | -------------- |
| At least one matches | All must match |

---

# Time Complexity

| Method     | Complexity |
| ---------- | ---------- |
| push()     | O(1)       |
| pop()      | O(1)       |
| shift()    | O(n)       |
| unshift()  | O(n)       |
| indexOf()  | O(n)       |
| includes() | O(n)       |
| slice()    | O(n)       |
| splice()   | O(n)       |
| sort()     | O(n log n) |
| reverse()  | O(n)       |
| map()      | O(n)       |
| filter()   | O(n)       |
| reduce()   | O(n)       |

# Interview Questions

### Difference between Array and Object?

* **Array** stores ordered values using indexes.
* **Object** stores key-value pairs.

---

### Is an Array an Object?

Yes.

```javascript
typeof [];
```

**Output**

```javascript
"object"
```

---

### How to check if a variable is an array?

```javascript
Array.isArray(arr);
```

---

### Why is `sort()` incorrect for numbers?

```javascript
[10, 2, 30].sort();
```

**Output**

```javascript
[10, 2, 30]
```

Correct way:

```javascript
[10, 2, 30].sort((a, b) => a - b);
```
